Phase 3 · One-time · 2 min

Create a GitHub Access Token

This lets the automation update your settings automatically when tokens expire

15
Why do you need this?
Simple explanation

Your LinkedIn login token expires roughly every 60 days. When it does, the automation silently renews it — but it needs your permission to save the new token back to GitHub. This GitHub token gives it that permission.

Without it, the automation will stop working after 60 days and you'd have to manually update it.

🔑
You only do this once. After that it renews itself forever automatically.
16

7

8

10

Troubleshooting — if something goes wrong
Every possible error with the exact fix
🔴
Error: "requested permission scope is not valid"
You're missing the Sign In with LinkedIn using OpenID Connect product.
→ LinkedIn Developer App → Products tab → find it → Request Access → re-run get_token.py → update the 4 LI_ secrets in GitHub
🟠
Error: "w_member_social is not authorized"
You're missing the Share on LinkedIn product.
→ LinkedIn Developer App → Products tab → find it → Request Access → re-run get_token.py → update the 4 LI_ secrets in GitHub
🔴
Error: "redirect_uri_mismatch"
The callback URL in your LinkedIn app is wrong.
→ LinkedIn Developer App → Auth tab → make sure redirect URL is exactly http://localhost:8989/callback → click Update → re-run get_token.py
🔴
Error: "Missing environment variables" in GitHub Actions
A secret name is wrong or missing.
→ Your repo on GitHub → Settings → Secrets and variables → Actions → check all 9 secret names match exactly — copy-paste them from Phase 4 in this guide
🔴
Error: 401 Unauthorized
Your LinkedIn access token has expired.
→ Re-run get_token.py on your laptop → copy the 4 new LI_ values → update those 4 secrets in GitHub
🟡
No post published — "No posts ready to publish"
There are no post_*.txt files in the content folder.
→ Add post files and upload them via GitHub Desktop
🟡
Nothing posts on Saturday or Sunday
Normal! If POST_SCHEDULE is set to weekdays it skips weekends.
→ Change POST_SCHEDULE to all in GitHub Secrets if you want daily posting including weekends
🔵
Post goes out but has no image
The image filename doesn't match the post number.
→ Check the image is named post_n_image.jpg where n matches the post number (e.g. post_1.txt needs post_1_image.jpg)
🔵
Workflow doesn't fire at the right time
GitHub can be up to 15 minutes late on its schedule. Also repos that haven't been updated in 60 days have their Actions paused.
→ Just upload any file via GitHub Desktop to wake it back up
🔵
Posts suddenly stop after many months
Your refresh token expired (this happens about once a year).
→ Re-run get_token.py on your laptop → copy all 6 token values → update the 4 LI_ token secrets in GitHub. You won't need to do this more than once a year.
