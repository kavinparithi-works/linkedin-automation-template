Phase 3 · One-time · ~2 min

Create a GitHub Personal Access Token (GH_PAT)

Needed so the workflow can auto-update secrets and send failure email alerts

9
Why is GH_PAT needed?
The built-in GITHUB_TOKEN cannot update secrets or create issues
  • 🔄 Auto-update GitHub Secrets when LinkedIn access token refreshes — so next run always has valid tokens
  • 🚨 Create a GitHub Issue (which sends you an email) when a run fails
🔑
Most important new step. Without GH_PAT, token refresh works but new tokens won't be saved — the next run after expiry will fail with a 401 error.

POST_SCHEDULE — all options explained
Set via GitHub Secret
"all" Posts every pending file on every run — bulk publishing
"weekdays" One post per run, Mon–Fri only, incremental (post_1 → post_2 → …)
"2026-06-15" Posts once on that exact date only — good for announcements
"MON,WED,FRI" One post per run on those days only — valid tokens: MON TUE WED THU FRI SAT SUN

Troubleshooting — complete error reference
Every error you might see, with exact fixes
🔴
invalid_scope_error — "permission scope is not valid"
Missing product: Sign In with LinkedIn using OpenID Connect
→ Products tab → find it → Request Access → re-run get_token.py
🟠
unauthorized_scope_error — "w_member_social is not authorized"
Missing product: Share on LinkedIn
→ Products tab → find it → Request Access → re-run get_token.py
🔴
redirect_uri_mismatch
Wrong redirect URL in LinkedIn app
→ Auth tab → must be exactly http://localhost:8989/callback (no slash, no https) → Update → re-run
🔴
Missing environment variables (GitHub Actions)
A secret name is wrong or missing
→ Repo → Settings → Secrets → compare each name exactly against the Phase 4 list
🔴
401 Unauthorized from LinkedIn API
Access token invalid or expired
→ Run get_token.py → update LI_ACCESS_TOKEN and LI_ACCESS_TOKEN_EXPIRES_AT in GitHub Secrets
🟡
No posts ready to publish
No post_*.txt files in content/
→ Add content files and push to GitHub
🟡
Nothing posts on weekends
Normal if POST_SCHEDULE = "weekdays"
→ Change to "all" to post every day
🔵
Post goes out with no image
Image filename mismatch
→ Must be exactly post_n_image.jpg where n matches the text file number
🔵
Workflow not firing at scheduled time
GitHub cron can delay up to 15 min. Repos inactive 60+ days have Actions paused
→ Push any file to re-activate
🔵
Refresh token expired (~1 year from now)
Run get_token.py locally → get new tokens → update all 4 LI_* token secrets in GitHub. Happens at most once a year.
